Comment jouer

← → rester sur la piste, y compris dans les virages

↓ maintenu dans les descentes des bosses pour pomper, relâché dans les montées

↑ seulement sur les sauts pour tirer plus loin (↓ sur un saut = raser, moins loin)

Espace + ↑ frontflip, + ↓ backflip, + → 360 : au décollage du gros saut

En l'air : Espace seul = trick de style, Espace + ← = tailwhip

◀ ▶ rester sur la piste, y compris dans les virages

▼ maintenu dans les descentes des bosses pour pomper, relâché dans les montées

▲ seulement sur les sauts, pour tirer plus loin. Le bouton qui clignote avant un saut te montre quoi faire.

TRICKS maintenu + ▲ frontflip, ▼ backflip, ▶ 360 : au décollage du gros saut. En l'air : TRICKS seul = trick de style, TRICKS + ◀ = tailwhip

C'est la vitesse qui fait gagner : enchaîne les PERFECT. Les tricks remplissent la barre de hype pour un boost.
